# Numbers — Sorteador de Números 🔢✨

![Preview do projeto Numbers](assets/numbers-preview.png)

O **Numbers** é um projeto desenvolvido em **JavaScript puro**, criado para realizar sorteios de números de forma simples, rápida e visualmente agradável.  
O usuário define o intervalo, escolhe quantos números deseja sortear e visualiza o resultado com uma animação dinâmica e fluída — tudo diretamente na tela.

Esse projeto é ideal para quem deseja praticar:
- Manipulação do **DOM**
- Tratamento e validação de formulários
- Controle de estado na interface
- CSS com animações personalizadas
- Lógica de geração aleatória

---

## ✨ Funcionalidades

- Definir:
  - Quantidade de números a sortear
  - Valor mínimo do intervalo
  - Valor máximo do intervalo
  - Opção de evitar números repetidos
- Validação automática dos campos:
  - Impede intervalo inválido
  - Impede quantidade de números maior que o possível
- Exibição dinâmica dos resultados
- Animação individual para cada número sorteado
- Histórico de sorteios exibido como:
  - "1º resultado"
  - "2º resultado"
  - "3º resultado"
  - ... e assim por diante
- Layout moderno, responsivo e com visual minimalista
